1. Physical Maze Grid

We begin with a physical grid representation of the environment. The maze contains traversable corridor cells, black wall obstacles, a starting location S, and a goal location G.

Grid Size: 15 × 11
Total Grid Cells: 165 cells
Traversable Cells (K): 70
In a physical grid, search algorithms must explore cell-by-cell. For large grids, this creates a massive search space. Can we abstract this environment?

3. First Abstraction — 4T State Space

A navigation decision is only needed at turning points, corners, dead-ends, the start (S), or the goal (G). Intermediate grid cells along straight corridors are abstracted away.

State = (Turning Point, Orientation)
Turning Points (T): 25
Orientations: 4
State Space Size: 100
State space is reduced from 4K (280) to 4T (100) states. We have removed intermediate grid points, but we still retain orientation because it affects steering.

4. Second Abstraction — T State Space

Instead of low-level steering, we allow abstract actions to move directly from one turning point to the next. Orientation is implicitly handled by the actions and removed from the state.

5. Abstract Graph Construction

We connect turning points by tracing the corridors. Each abstract action represents a direct path between nodes, with the cell distance as the transition cost.

Original Space: 280 states
Abstract Space: 25 states
Total Reduction: 91%
The dynamically derived abstract graph consists of:
• Nodes: Turning points (Start, Goal, Corners, Intersections).
• Edges: Corridors between nodes.
• Cost: Cell distance along each corridor (edge weight).

1. 8-Puzzle Setup

The standard 8-puzzle contains 8 numbered tiles and 1 empty position (blank space '_') on a 3 × 3 grid. The target is to rearrange the tiles from their initial arrangement to the goal arrangement.

Grid Size: 3 × 3
Tiles: 1 - 8
Blank Position: 1
A state in the 8-puzzle is a single, complete configuration of tiles and the blank. Moving a tile changes the puzzle state.

2. State Representation

To store the board state in computer memory, we represent it as a simple, immutable 9-element list or tuple: (7, 2, 4, 5, 0, 6, 8, 3, 1), where 0 denotes the blank position.

state = (7, 2, 4, 5, 0, 6, 8, 3, 1)
Any two boards with tiles in different positions represent different states. For example, (7,2,4,5,0,6,8,3,1) ≠ (7,2,4,5,3,6,8,0,1). Complete board arrangements define unique states.

3. Actions & Transition Model

The transition model defines which actions are possible in a state, and the resulting state after applying an action: RESULT(s, a) = s'. In this puzzle, we define actions from the perspective of moving the blank space.

4. Possible Configurations Size

How many total arrangements of the 8 tiles and blank are mathematically possible? Since there are 9 slots, there are 9 factorial total arrangements:

9! = 362,880 possible arrangements
But are all of these 362,880 arrangements actually reachable from our initial configuration? Let's analyze reachability next.

5. Parity & Solvability Presets

The 362,880 arrangements form two completely disconnected components (parity classes) of size 181,440. You can only move within your group; legal moves cannot cross the parity divide.

8. Concept Summary

A quick-reference guide of core AI Search concepts taught by the 8-puzzle demo:

Question Concept / Answer
What is a state? One unique board arrangement of tiles & blank
What is a state space? Set of all theoretically possible configurations (9! = 362,880)
What are actions? Moves of blank space (Up, Down, Left, Right)
What is the transition model? RESULT(s, a) yielding a new state s'
Are all states reachable? No, parity constraints divide permutations into 2 disconnected groups
Reachable state space? Set of states obtainable from initial state (size: 9!/2 = 181,440)
What is a goal state? A target configuration (which must share the initial state's parity)
