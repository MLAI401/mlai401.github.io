Curriculum

A systematic progression through foundational Artificial Intelligence and Machine Learning — from problem formulation to generative, agentic AI. Each topic is paired with a hands-on demo in the Playground.

Topic 01

Problem Formulation

Describing a task as a search problem — initial state, actions, transition model, goal test, and path cost — and abstracting a physical environment into states and a graph.

  • Vacuum World — agents Try it
  • Maze → State Space Try it
  • 8-Puzzle → State Space Try it
Topic 02

Search & Planning

One problem solved with BFS, DFS, Uniform-Cost, Greedy Best-First, and A* — comparing frontier, explored nodes, path, and cost, plus adversarial search against an opponent.

  • Route-Finding Visualizer Try it
  • Tic-Tac-Toe Planned
Topic 03

Constraint Satisfaction

Variables, domains, and constraints — assigning values, detecting conflicts, and backtracking to reach a solution that satisfies every constraint.

  • Scheduling Planned
Topic 04

Knowledge & Reasoning

Going from facts and rules to new conclusions through logical inference, and from a prior belief to a posterior belief through evidence under uncertainty.

  • Mini Knowledge Agent Planned
  • Bayesian Reasoning Demo Planned
Topic 05

Learning & Decision Making

Learning patterns from labeled examples rather than explicitly programmed rules, and learning a better policy through state → action → reward interaction.

  • Classification Demo Planned
  • Grid World Agent Planned
Topic 06

Generative & Agentic AI

A goal-driven agent that reasons about a task, plans, acts, observes results, and replans — using tools and memory, and coordinating with other agents to complete work.

  • Goal-Driven AI Agent Planned
  • Two-Agent Task Planned
